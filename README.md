# Unicorn Coloring Book

A ready-to-sell, 24-page unicorn coloring book for kids ages 4-8, generated
entirely from original vector-style artwork (no stock art, no AI-image
licensing questions — you own every line).

## What's in `output/` (the files you actually need)

| File | What it's for |
|---|---|
| `Unicorn-Coloring-Book-Interior.pdf` | The book's interior: title page + 24 designs, each followed by a blank page (so crayon/marker doesn't bleed through to the next picture). 49 pages, 8.5×11in, black & white. Upload this as the **interior** on KDP. |
| `Unicorn-Coloring-Book-FrontCover.png` | Full-color front cover art, 8.5×11in. |
| `Unicorn-Coloring-Book-BackCover.png` | Full-color back cover art with blurb, 8.5×11in. |
| `Unicorn-Coloring-Book-Cover-Preview.pdf` | Front + back cover together, for quickly previewing or sharing. |

## Selling it online

**Option A — Print-on-demand via Amazon KDP (what the screenshot you were browsing is an example of):**
1. Create a KDP account at kdp.amazon.com → "Paperback" → low-content/coloring book.
2. Trim size: **8.5 × 11 in**. Interior: black & white, white paper.
3. Upload `Unicorn-Coloring-Book-Interior.pdf` as the interior. KDP will tell you the exact page count (49) and, from that, the required **spine width** for the cover.
4. For the cover, use KDP's free **Cover Creator**: choose "upload your own front and back cover images" and hand it `Unicorn-Coloring-Book-FrontCover.png` and `Unicorn-Coloring-Book-BackCover.png` — it lays them out on the wraparound template with the correct spine automatically (safer than hand-building the spine width yourself, since it depends on the exact paper KDP assigns).
5. Leave the bottom-right ~2×1.2in corner of the back cover free of your own text/art for KDP's auto-generated ISBN barcode — this book's back cover already keeps that corner clear.
6. Price: similar coloring books (like the one you were looking at) sell for $5.99–$8.99 (or the local equivalent). KDP shows your royalty live as you set the price — start around $6.99 and adjust.

**Option B — Sell the PDF directly (Etsy digital download, Gumroad, your own site):**
- No printing needed — buyers print at home. List `Unicorn-Coloring-Book-Interior.pdf` (you may want to drop the blank pages for a digital version — see "Regenerating" below) plus the front cover PNG as your listing thumbnail.
- Typical price for a 24-page digital coloring book: $3–$6.
- This is the fastest way to start selling — no print setup, no shipping, and you can list it today.

**Option C — Other print-on-demand (Printful, Printify, etc.):** most support custom "coloring book" or booklet products; upload the interior PDF and cover PNGs the same way.

## Regenerating or customizing

Everything is generated by Python scripts in `build/` — no external image
assets, no network access required, so you can freely tweak and re-run.

```
pip install Pillow
cd build
python3 make_pages.py   # regenerates book/pages/page_01.png ... page_24.png
python3 make_cover.py   # regenerates book/cover/front_cover.png and back_cover.png
python3 make_pdf.py     # assembles everything into output/
```

- `build/drawlib.py` — low-level shape helpers (bezier curves, stars, hearts, flowers, clouds, etc.)
- `build/unicorn.py` — the unicorn character in 5 poses (standing, sitting, lying, flying, rearing) plus a portrait close-up
- `build/make_pages.py` — the 24 page scene compositions and their titles
- `build/make_cover.py` — the full-color front/back cover art
- `build/make_pdf.py` — assembles the PNGs into the final print-ready PDFs

To add more pages: write a new `pXX(draw)` function in `make_pages.py` using
the existing helpers, add it to the `PAGES` list with a title, and re-run.
To change the theme entirely (e.g. dinosaurs, farm animals), the same
`drawlib.py` shape toolkit can build a new character module alongside
`unicorn.py`.

## Notes on the artwork

The original plan was to generate the illustrations with an AI image model,
but this session's network policy blocks the image host, so the book was
built as original hand-coded vector art instead — every shape is drawn from
bezier curves and geometric primitives in Python. That means there are no
stock-image or AI-generation licensing questions at all: you own the
artwork outright and can sell it without attribution.
